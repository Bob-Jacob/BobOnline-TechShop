# ОПИСАНИЕ КУРСОВОЙ РАБОТЫ

## НАЗВАНИЕ ТЕМЫ
**Разработка веб-приложения для интернет-магазина цифровых товаров с системой управления лицензионными ключами**

## ЦЕЛЬ РАБОТЫ
Разработать полнофункциональное веб-приложение для продажи цифровых товаров (лицензии, игры, программное обеспечение, подписки, онлайн-курсы и др.) с автоматизированной системой управления лицензионными ключами, корзиной покупок, обработкой заказов и админ-панелью для управления контентом и пользователями.

## ЗАДАЧИ
1. Реализовать систему аутентификации и авторизации пользователей с ролевой моделью (USER, ADMIN)
2. Создать каталог товаров с категоризацией и поиском
3. Разработать систему корзины покупок с возможностью изменения количества товаров
4. Реализовать процесс оформления и оплаты заказов
5. Создать систему управления лицензионными ключами с автоматическим назначением при покупке
6. Разработать админ-панель для управления товарами, заказами, пользователями и ключами
7. Реализовать систему уведомлений по электронной почте
8. Создать функционал избранного и профиля пользователя
9. Реализовать систему статистики и аналитики для администратора

## ЧТО РЕАЛИЗОВАНО

### 1. Система аутентификации и авторизации
- Регистрация новых пользователей с валидацией данных
- Вход в систему по email и паролю
- Ролевая модель доступа (USER, ADMIN)
- Защита маршрутов с помощью Spring Security
- Хеширование паролей с использованием BCrypt
- Автоматическое создание ролей при инициализации приложения

### 2. Каталог товаров
- Отображение всех товаров на главной странице
- Фильтрация товаров по категориям
- Поиск товаров по названию
- Детальная страница товара с описанием, ценой, остатком
- Категории товаров:
  - Лицензии игр
  - Лицензии ПО
  - Подписки
  - VPN-доступ
  - Хостинг и домены
  - Облачное хранилище
  - Электронные книги
  - Онлайн-курсы
  - Шаблоны, темы, плагины

### 3. Корзина покупок
- Добавление товаров в корзину с указанием количества
- Просмотр содержимого корзины
- Изменение количества товаров в корзине (кнопки +/-)
- Удаление товаров из корзины
- Автоматический расчет общей суммы
- Проверка наличия товара на складе
- Автоматическая очистка корзины после оформления заказа
- Отображение количества товаров в корзине в шапке сайта

### 4. Система заказов
- Оформление заказа из корзины
- Создание заказа со статусом PENDING
- Просмотр истории заказов пользователя
- Детальная информация о заказе
- Статусы заказов:
  - PENDING (Ожидает оплаты)
  - PAID (Оплачен)
  - COMPLETED (Выполнен)
  - CANCELLED (Отменен)

### 5. Система оплаты
- Создание платежа при оформлении заказа
- Мок-система оплаты (симуляция успешной оплаты)
- Автоматическое обновление статуса заказа после оплаты
- Автоматическая выдача товаров после оплаты:
  - Назначение лицензионных ключей
  - Отправка ссылок на скачивание цифровых товаров
  - Уменьшение остатков товаров

### 6. Система лицензионных ключей
- Управление лицензионными ключами для товаров
- Автоматическое назначение ключей при покупке
- Отслеживание использованных и доступных ключей
- Массовая загрузка ключей из текстового файла
- Автоматическая синхронизация остатков товаров с количеством доступных ключей
- Отправка ключей покупателю на email после оплаты

### 7. Избранное
- Добавление товаров в избранное
- Удаление товаров из избранного
- Просмотр списка избранных товаров
- Проверка статуса товара в избранном

### 8. Профиль пользователя
- Просмотр информации об аккаунте
- Изменение email адреса
- Форма связи с поддержкой (отправка email администратору)

### 9. Админ-панель
- **Дашборд с аналитикой:**
  - Статистика по товарам, заказам, пользователям, выручке
  - Графики заказов по месяцам (последние 6 месяцев)
  - График товаров по категориям
  - График статусов заказов
  - Статистика лицензионных ключей
  - Топ-5 пользователей по количеству заказов
  - Топ-5 товаров по продажам
  - Список последних купленных ключей

- **Управление товарами:**
  - Просмотр всех товаров
  - Добавление нового товара
  - Редактирование товара
  - Удаление товара
  - Загрузка файлов для цифровых товаров
  - Установка флага "требуется лицензионный ключ"

- **Управление заказами:**
  - Просмотр всех заказов
  - Детальная информация о заказе
  - Изменение статуса заказа
  - Просмотр информации о пользователе и товарах в заказе

- **Управление пользователями:**
  - Просмотр всех пользователей
  - Блокировка/разблокировка пользователей
  - Назначение/удаление роли ADMIN
  - Просмотр статистики по пользователю (количество заказов, купленных ключей)

- **Управление лицензионными ключами:**
  - Выбор товара для управления ключами
  - Добавление ключа вручную
  - Массовая загрузка ключей из файла
  - Просмотр всех ключей товара с информацией об использовании

### 10. Система уведомлений
- Отправка email при оформлении заказа
- Отправка лицензионных ключей на email после оплаты
- Отправка ссылок на скачивание цифровых товаров
- Отправка обращений в поддержку администратору

## КАК ЭТО РАБОТАЕТ

### Процесс покупки товара:

1. **Просмотр каталога** → Пользователь просматривает товары на главной странице или в каталоге
2. **Добавление в корзину** → При нажатии "Добавить в корзину" товар добавляется в корзину пользователя
3. **Управление корзиной** → Пользователь может изменить количество или удалить товары
4. **Оформление заказа** → При нажатии "Оформить заказ" создается заказ со статусом PENDING, корзина очищается
5. **Оплата** → Пользователь переходит на страницу оплаты и нажимает "Оплатить" (мок-оплата)
6. **Обработка заказа:**
   - Статус заказа меняется на PAID
   - Для товаров с лицензионными ключами: автоматически назначаются доступные ключи
   - Для цифровых товаров: готовятся ссылки на скачивание
   - Остатки товаров уменьшаются
   - Статус заказа меняется на COMPLETED
7. **Отправка уведомлений** → Пользователю на email отправляются:
   - Подтверждение заказа
   - Лицензионные ключи (если есть)
   - Ссылки на скачивание (если есть)

### Управление лицензионными ключами:

1. Администратор добавляет ключи для товара через админ-панель
2. При добавлении ключа остаток товара автоматически обновляется (если товар требует ключи)
3. При покупке товара система автоматически:
   - Находит доступный неиспользованный ключ
   - Помечает его как использованный
   - Связывает с заказом
   - Отправляет на email покупателю

## ФУНКЦИОНАЛ ПОЛЬЗОВАТЕЛЯ

### Неавторизованный пользователь может:
- Просматривать каталог товаров
- Просматривать детальную информацию о товаре
- Искать товары по названию
- Фильтровать товары по категориям
- Регистрироваться в системе
- Входить в систему

### Авторизованный пользователь (USER) может:
- Все функции неавторизованного пользователя
- Добавлять товары в корзину
- Просматривать корзину
- Изменять количество товаров в корзине
- Удалять товары из корзины
- Оформлять заказы
- Оплачивать заказы
- Просматривать историю своих заказов
- Просматривать детали заказа
- Добавлять товары в избранное
- Удалять товары из избранного
- Просматривать список избранных товаров
- Просматривать свой профиль
- Изменять email адрес
- Отправлять обращения в поддержку

### Администратор (ADMIN) может:
- Все функции обычного пользователя
- Просматривать админ-панель с аналитикой
- Управлять товарами (CRUD операции)
- Загружать файлы для цифровых товаров
- Управлять заказами (просмотр, изменение статуса)
- Управлять пользователями (просмотр, блокировка, назначение ролей)

- Просматривать статистику:
  - Общее количество товаров, заказов, пользователей
  - Выручка
  - Графики по месяцам и категориям
  - Топ пользователей и товаров
  - Статистика по ключам

## БАЗА ДАННЫХ

### Таблицы и их структура:

#### 1. **users** (Пользователи)
- `id` (BIGINT, PRIMARY KEY, AUTO_INCREMENT)
- `email` (VARCHAR, UNIQUE, NOT NULL)
- `password` (VARCHAR, NOT NULL) - хешированный пароль
- `enabled` (BOOLEAN, NOT NULL, DEFAULT true)
- `created_at` (TIMESTAMP, NOT NULL)

#### 2. **roles** (Роли)
- `id` (BIGINT, PRIMARY KEY, AUTO_INCREMENT)
- `name` (VARCHAR, UNIQUE, NOT NULL) - USER или ADMIN

#### 3. **user_roles** (Связь пользователей и ролей)
- `user_id` (BIGINT, FOREIGN KEY → users.id)
- `role_id` (BIGINT, FOREIGN KEY → roles.id)

#### 4. **products** (Товары)
- `id` (BIGINT, PRIMARY KEY, AUTO_INCREMENT)
- `name` (VARCHAR, NOT NULL)
- `description` (TEXT)
- `price` (DECIMAL(10,2), NOT NULL)
- `category` (VARCHAR, NOT NULL) - enum ProductCategory
- `stock` (INTEGER, NOT NULL, DEFAULT 0)
- `image_url` (VARCHAR)
- `file_url` (VARCHAR) - для цифровых товаров
- `requires_license_key` (BOOLEAN, DEFAULT false)
- `created_at` (TIMESTAMP, NOT NULL)

#### 5. **carts** (Корзины)
- `id` (BIGINT, PRIMARY KEY, AUTO_INCREMENT)
- `user_id` (BIGINT, FOREIGN KEY → users.id, UNIQUE, NOT NULL)
- `created_at` (TIMESTAMP, NOT NULL)

#### 6. **cart_items** (Позиции корзины)
- `id` (BIGINT, PRIMARY KEY, AUTO_INCREMENT)
- `cart_id` (BIGINT, FOREIGN KEY → carts.id, NOT NULL)
- `product_id` (BIGINT, FOREIGN KEY → products.id, NOT NULL)
- `quantity` (INTEGER, NOT NULL, DEFAULT 1)

#### 7. **orders** (Заказы)
- `id` (BIGINT, PRIMARY KEY, AUTO_INCREMENT)
- `user_id` (BIGINT, FOREIGN KEY → users.id, NOT NULL)
- `total_price` (DECIMAL(10,2), NOT NULL)
- `status` (VARCHAR, NOT NULL) - enum OrderStatus
- `created_at` (TIMESTAMP, NOT NULL)

#### 8. **order_items** (Позиции заказа)
- `id` (BIGINT, PRIMARY KEY, AUTO_INCREMENT)
- `order_id` (BIGINT, FOREIGN KEY → orders.id, NOT NULL)
- `product_id` (BIGINT, FOREIGN KEY → products.id, NOT NULL)
- `quantity` (INTEGER, NOT NULL)
- `price` (DECIMAL(10,2), NOT NULL)

#### 9. **payments** (Платежи)
- `id` (BIGINT, PRIMARY KEY, AUTO_INCREMENT)
- `order_id` (BIGINT, FOREIGN KEY → orders.id, UNIQUE, NOT NULL)
- `amount` (DECIMAL(10,2), NOT NULL)
- `status` (VARCHAR, NOT NULL) - enum PaymentStatus
- `payment_method` (VARCHAR, DEFAULT 'MOCK')
- `transaction_id` (VARCHAR)
- `created_at` (TIMESTAMP, NOT NULL)

#### 10. **license_keys** (Лицензионные ключи)
- `id` (BIGINT, PRIMARY KEY, AUTO_INCREMENT)
- `product_id` (BIGINT, FOREIGN KEY → products.id, NOT NULL)
- `key` (VARCHAR, UNIQUE, NOT NULL)
- `is_used` (BOOLEAN, NOT NULL, DEFAULT false)
- `used_at` (TIMESTAMP)
- `order_id` (BIGINT, FOREIGN KEY → orders.id)
- `created_at` (TIMESTAMP, NOT NULL)

#### 11. **favorites** (Избранное)
- `id` (BIGINT, PRIMARY KEY, AUTO_INCREMENT)
- `user_id` (BIGINT, FOREIGN KEY → users.id, NOT NULL)
- `product_id` (BIGINT, FOREIGN KEY → products.id, NOT NULL)
- `created_at` (TIMESTAMP, NOT NULL)
- UNIQUE constraint на (user_id, product_id)

### Связи между таблицами:
- User → Cart (One-to-One)
- User → Orders (One-to-Many)
- User → Favorites (One-to-Many)
- User ↔ Role (Many-to-Many через user_roles)
- Cart → CartItem (One-to-Many)
- Product → CartItem (One-to-Many)
- Order → OrderItem (One-to-Many)
- Product → OrderItem (One-to-Many)
- Order → Payment (One-to-One)
- Product → LicenseKey (One-to-Many)
- Order → LicenseKey (One-to-Many)
- User → Favorite (One-to-Many)
- Product → Favorite (One-to-Many)

## ОСОБЕННОСТИ РЕАЛИЗАЦИИ

1. **Автоматическое управление остатками** - для товаров с лицензионными ключами остаток автоматически синхронизируется с количеством доступных ключей

2. **Транзакционность операций** - все критические операции (создание заказа, оплата, выдача ключей) выполняются в транзакциях

3. **Безопасность** - пароли хешируются с помощью BCrypt, защита от CSRF, ролевая модель доступа

4. **Адаптивный дизайн** - интерфейс адаптируется под различные размеры экранов

5. **AJAX запросы** - для обновления корзины, избранного без перезагрузки страницы

6. **Валидация данных** - на стороне клиента и сервера

7. **Обработка ошибок** - глобальный обработчик исключений

8. **Логирование** - все важные операции логируются

## ЗАКЛЮЧЕНИЕ

Разработано полнофункциональное веб-приложение для интернет-магазина цифровых товаров с автоматизированной системой управления лицензионными ключами, корзиной покупок, обработкой заказов и админ-панелью. Приложение обеспечивает удобный процесс покупки для пользователей и полный контроль над магазином для администраторов.
